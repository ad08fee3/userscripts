# amazonUrlSimplifier

[Install](https://github.com/ad08fee3/userscripts/raw/refs/heads/main/userscripts/amazonUrlSimplifier/amazonUrlSimplifier.user.js)

Simplifies Amazon URLs to the shortest-necessary link to make sharing links nicer.

Don't you love when you want to copy-paste a link, and you accidentally send your friend _this?_
```
https://www.amazon.com/Embroidered-Clutch-Dressy-Envelope-Evening/dp/B0GQSWL289?_encoding=UTF8&pd_rd_w=hiXXr&content-id=amzn1.sym.8923efa3-3932-4ad7-b762-70b11a6fb674&pf_rd_p=8923efa3-3932-4ad7-b762-70b11a6fb674&pf_rd_r=AN1SC13CZ9Z51SX3FJCD&pd_rd_wg=xUDRW&pd_rd_r=2a0c9168-81af-407e-8809-e8a56c59983c&th=1
```

This script instead shortens all Amazon pages to the shortest value necessary:

![alt text](image.png)

So now you can copy-paste without annoyance.
