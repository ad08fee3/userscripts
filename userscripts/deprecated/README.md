# Deprecated userscripts

This folder contains userscripts that are no longer maintained, usually because Refined GitHub (or a newer script in this repo) now covers the same behavior. They are kept here for reference, or in case others don't want to use Refined GitHub.

| Script | Description |
| --- | --- |
| [githubFullWidthNewFiles](githubFullWidthNewFiles/README.md) | Makes wholly-added or wholly-deleted files use the full portal width in side-by-side diffs. Now covered by Refined GitHub. |
| [githubDiffWhitespace](userscripts/githubDiffWhitespace/README.md) | Hides whitespace changes in GitHub diffs by default, while still letting you opt back in. Now built into GitHub directly! |
